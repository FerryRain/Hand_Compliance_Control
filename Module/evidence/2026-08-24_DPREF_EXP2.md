## 1. 已实现的控制链

```text
future wrist plan + causal hand/contact history
 -> shared encoder
 -> diffusion head: measured-q anchored q_nom chunk
 -> categorical head: KEEP / RELEASE / FREE / MAKE intention
 -> deterministic Reference/Role Interpreter
 -> Resultant/Internal Coordinator
 -> shared Wrist MCC + Finger MCC
 -> M03 command-continuity limiter and force-safety guard
```

- Role head 与 diffusion action 分开训练；role 使用 masked class-balanced cross entropy。
- Role 请求必须持续确认；执行状态只允许 `KEEP -> RELEASE -> FREE -> MAKE -> KEEP`。
- `RELEASE` 先停止切向推进，再把目标力平滑降到 0；真实 contact clear 后才进入 `FREE`。
- Wrist MCC 负责 collective/resultant compliance；Finger MCC 负责 internal/local force；DPRef
  只负责 nominal coordination 和 transition intention。
- `q_meas`、上一轮 `q_nom` 和先前 MCC correction 是三个独立输入，不把低层修正当作 nominal
  teacher action。

## 5. Exp. 2：相同 MCC，只替换 reference source

三路共享 wrist trajectory、Wrist MCC、resultant/internal coordinator、Finger MCC、Role
Interpreter、M03、robot/object/initial states；唯一变量是 nominal reference/role-intention source。

| aggregate（3 条件均值） | Passive-Hold+MCC | Reactive-Heuristic+MCC | DPRef+MCC |
| --- | ---: | ---: | ---: |
| contact continuity | 0.875 | 0.859 | 0.877 |
| average contacts | 1.511 | 1.447 | 1.419 |
| supported Y, `N_c>=2` | 51.76 mm | 49.34 mm | 46.13 mm |
| worst peak force | 7.545 N | 10.050 N | 6.571 N |
| 相对 8 N 峰值越界 | 0 N | 2.050 N | 0 N |
| DPRef inference P95 | n.a. | n.a. | 13.96 ms（3 条件均值） |

描述性性能判断：

- Passive 的平均接触数与 `N_c>=2` supported traversal 最高；
- Reactive 的 total traversal 最高，但峰值超过 8 N 2.05 N；
- DPRef 峰值最低且 continuity 略高，但平均接触数与 supported traversal 最低；
- validation 缺 RELEASE，不能从本实验声称 handover generalization。

Exp. 2 状态为 `EVALUATED`，不设置策略 Gate。当前结果没有显示 learned anticipatory reference
在多接触移动上的优势，但不阻塞其他模块；Exp. 3 由完整 active-system 依赖决定。
