## v3 逐指主动调形与控制交接

长程诊断发现 index 在关节限位处仍发出 SEEK，但旧 DLS 裁剪后目标方向实际进展很小；middle 的目标常超出 60 mm 局部搜索门限，不能靠增大时间预算解决。新版独立入口 `coordinated_surface_slide.py` 保留冻结 v2.2，新增以下机制：

- `active_fingers_v3.py` 在同一 8 µm/2 ms 笛卡尔、1 mrad/2 ms 额外关节增量、±0.5 rad 偏置及原关节范围内做有界求解。重规划不再擦除持续失联和搜索预算。真实安全接触连续 150 ms 才重置 episode；显式批准的调形路径可启动新局部尝试，每个 episode 最多 3 次。
- `finger_participation.py` 每个 2 ms 原生时刻观察实际关节、指腹几何中心和力。比较同一个当前目标下的实际位移，避免把目标移动或 SEEK 命令当进展。失联 3 s 后，持续低进展或远距可请求调形；全局/逐指冷却 8/20 s，跨 stroke 保留。
- 优先固定手腕，只用该指四个关节在原范围内重新调形，目标使用随指腹旋转变化的真实椭球支撑向量；整段密集碰撞检查通过才执行。必要时尝试保留接触支撑的 3°/6°小幅腕姿调整。有限候选失败仅表示没有找到解。
- 固定腕单指路径允许其他指短暂失联，仍由原生力、碰撞和关节保护约束；借支撑点转腕时，支撑失联暂停路径，超过 60 ms 返回重新规划。都不把短失联直接判为整瓶失败。
- 选定指首次真实接触即停止原路径内推；150 ms 稳定后才报告恢复。保持已经施加的安全手指伺服预载，避免重置 MCC 时突然松开支撑指。原 MCC 参数与限幅不变，空中转移清除预载；有界搜索在包含该预载的实际参考上求解，避免重复叠加。完整命令继续经过原关节裁剪和碰撞检查。

## 主动寻触

`active_fingers.py` 根据每根指腹当前位置、实际椭球形状和原始表面生成最近的指腹中心目标。失联去抖 60 ms 后，以各指自身 Jacobian 向目标移动；每指最多 4 mm/s、40 mm 累计探索、12 s、关节偏移 ±0.5 rad、额外搜索关节速度 0.5 rad/s。目标每 50 ms 从当前实测姿态刷新，不驱动腕关节。任一指达到 8 N 暂停探索；其余整机碰撞/力/限速保护继续有效。
